# Xolid - Apartment Rental Catalog

Современное веб-приложение для просмотра списка квартир с фильтрацией, поддержка трех языков (таджикский, русский, английский).

## 📋 Особенности

- ✅ **CRUD операции** (Create, Read, Update, Delete) через REST API
- 🌐 **Трехязычная поддержка** (Таджикский, Русский, Английский)
- 🔍 **Фильтрация квартир** по комнатам и цене
- ⚡ **Skeleton Loading** - скелеты загрузки для лучшего UX
- 📱 **Адаптивный дизайн** 
- 🎨 **Чистый, современный интерфейс**
- 💾 **Сохранение фильтров в URL** параметрах
- 🚀 **Server Components** где это уместно
- 📊 **SWR для кеширования данных**

## 🛠 Стек технологий

- **Frontend**: Next.js 16, React 19, TypeScript
- **Backend**: JSON Server (mock API)
- **Стилизация**: CSS (чистый CSS с переменными)
- **Иконки**: Lucide React
- **Библиотеки**: SWR для кеширования

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск JSON Server (база данных)

В отдельном терминале:

```bash
npm run backend
```

Сервер запустится на порту **3001**

### 3. Запуск Dev сервера

```bash
npm run dev -- --webpack
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 📝 Документация компонентов

### Filter.tsx (в папке Filters.tsx)

```typescript
/**
 * Filters Component
 * 
 * Компонент фильтрации квартир по комнатам и цене.
 * 
 * Особенности:
 * - Фильтрация по количеству комнат (1, 2, 3, 4+)
 * - Фильтрация по диапазону цены
 * - Debounce для цены (450ms) для оптимизации
 * - Сохранение фильтров в URL параметрах
 * - Синхронизация при навигации (назад/вперед)
 * - Поддержка 3 языков
 */
```

**Props:**
- `locale: string` - Текущий язык (tg, ru, en)

**Функциональность:**
- Кнопки для выбора комнат (1, 2, 3, 4+)
- Input поля для минимальной и максимальной цены
- Debounce при вводе цены (450ms)
- Автоматическое сохранение в URL параметрах
- Кнопка для сброса фильтров

### ApartmentList.tsx

```typescript
/**
 * ApartmentList Component
 * 
 * Основной компонент для отображения списка квартир с фильтрацией.
 * 
 * Особенности:
 * - Использует SWR для кеширования данных
 * - Поддерживает фильтрацию по комнатам и цене через query параметры
 * - Показывает skeleton loading во время загрузки
 * - Обрабатывает ошибки подключения к API
 * - Поддерживает 3 языка (таджикский, русский, английский)
 */
```

**Props:**
- `locale: string` - Текущий язык

**Особенности:**
- Получает фильтры из URL параметров
- Делает запрос к API `/api/apartments` с фильтрами
- Показывает 6 skeleton карточек во время загрузки
- Обрабатывает ошибки подключения
- Показывает сообщение если результаты не найдены

### SkeletonCard.tsx

```typescript
/**
 * SkeletonCard Component
 * 
 * Отображает placeholder (скелет) карточки квартиры во время загрузки данных.
 * Использует CSS анимацию для создания эффекта shimmer.
 */
```

Простой компонент без пропсов. Показывает макет карточки квартиры для улучшения UX во время загрузки.

## 🌍 Многоязычность

Система основана на `localStorage` для хранения выбранного языка. Все компоненты поддерживают три языка:

- **TG** - Таджикский
- **RU** - Русский  
- **EN** - Английский

В Header компоненте есть кнопки для переключения языков. Выбранный язык сохраняется в `localStorage` и используется во всех компонентах.

## 📡 API Endpoints

### GET /api/apartments
Получить список квартир (с опциональной фильтрацией)

Query params:
- `rooms` - кол-во комнат
- `minPrice` - минимальная цена
- `maxPrice` - максимальная цена

### POST /api/apartments
Создать новую квартиру

Body:
```json
{
  "title_tg": "...",
  "title_ru": "...",
  "title_en": "...",
  "price": 50000,
  "rooms": 1,
  "area": 32,
  "image": "...",
  "description_tg": "...",
  "description_ru": "...",
  "description_en": "..."
}
```

### GET /api/apartments/[id]
Получить детали квартиры по ID

### PUT /api/apartments/[id]
Обновить квартиру по ID

### DELETE /api/apartments/[id]
Удалить квартиру по ID
